### 📖 Описание кейса:
💡 Разработка прототипа системы для **автоматической генерации тегов** к видео **по его содержанию, названию и описанию**.  
Система должна классифицировать видео по **иерархическому списку тегов** от кейсодержателя (**Рутуб**) и определять **наиболее вероятные категории и подкатегории**.
